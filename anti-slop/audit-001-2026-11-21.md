## 2. Issues Found During AFTER Audit & Resolved

1. **Severe Light/Dark theme clash in `styles.css`**: Previous dark-navy override at bottom of `styles.css` set light text (`#e6edf7`) while legacy and `.suite-*` cards hardcoded white backgrounds (`#ffffff`, `#fbfdff`). Replaced with unified Light (`:root`) and Dark (`html[data-theme="dark"]`) token layers covering all legacy and suite selectors.
2. **Flat 13-button navigation strip (`app.js`)**: Regrouped into `Speaking`, `2026 Skills`, and `Workspace` with a mobile collapsible `Menu` toggle (`< 768px`).
3. **Removed `outline: none` on `.ctw-input` (`styles.css`)**: Replaced with high-contrast `:focus-visible` outline across all form fields and buttons.
4. **Live Writing word-count meters (`toefl-suite-modules.js`)**: Added real-time progress bars for Email (`90-130w`) and Academic Discussion (`100-140w`) updating DOM directly on `input` without stealing textarea focus.
5. **Missing favicon 404**: Added inline SVG favicon to `index.html` so live browser requests return zero 404 console errors.
